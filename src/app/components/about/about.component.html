Acerca del Proyecto

Sistema de Gestión para Biblioteca Escolar

Propósito

Esta aplicación fue diseñada para digitalizar y optimizar el control de préstamos de libros, permitiendo un registro rápido de los alumnos y las fechas de devolución de manera eficiente y centralizada.

Tecnologías Utilizadas
Angular 17+ Bootstrap 5 TypeScript HTML5 & CSS3
